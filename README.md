# Amazon Clone Website

This is a **front-end clone of Amazon** built using **HTML, CSS, and Font Awesome**. The project replicates the layout and basic design of the Amazon website, including the navbar, search bar, hero section, product categories, and footer.

## Features

- Responsive **navigation bar** with logo, search bar, location, account, orders, and cart icons  
- **Hero section** with promotional message  
- **Product categories section** displaying various items like Clothes, Electronics, Furniture, Mobiles, etc.  
- **Footer** with multiple panels for links, information, and branding  
- Styled using **CSS Flexbox, background images, and hover effects**  
- Icons integrated via **Font Awesome**
- Images for hero section and product categories for realistic layout


## Project Structure

- `Amazon.html` — Main HTML page  
- `Amazon.css` — Styling for layout, colors, fonts, and hover effects  
- Images: `amazon_logo.png`, `hero_image.jpg`, `box1_image.jpg`, etc.  
- External resources: Font Awesome CDN for icons  

## How to Run

1. Clone or download the repository.  
2. Ensure all image files are in the same folder as `Amazon.html`.  
3. Open `Amazon.html` in any web browser.  

## Notes

- This is a **static website**, no backend functionality included.  
- Designed to be compatible with all modern browsers.  
- Perfect for learning **HTML structure, CSS styling, Flexbox, and layout design**.
